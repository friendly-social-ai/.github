# Friendly Social AI

A complementary organization to [friendly-social](https://github.com/friendly-social/).

Our main repository contains a [statement](https://github.com/friendly-social/knowledge/blob/main/AI.md) **against AI** use to generate code. And **pro-AI** use to research things.

Some of our members, however, do want to contribute their time, but they either don't have enough of it, or don't have enough desire to code manually and enjoy the process.

And we take that contribution for domains where we don't have enough human forces to work on things. Projects under this organization are allowed to:

* Have any code quality, you can stop reading it completely
* Have any features quality, you can implement sketches and ask us to upload it there as a funny experiment or something
* Even for fully human-reviewed projects, but AI-assisted, this is the right place

However, for the strategically important project, we will have a goal of replacing them with no ai product at some point.

For example, someone wants to vibe code a native desktop app for us right now. They will vibe-code it, but then our web part is finished, and @y9san9 can start developing desktop app themselves. Then in a year they implement native app with their own efforts. It will supersede AI-assisted version.
